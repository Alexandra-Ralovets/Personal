# FlowMeet: Подсказка на экране, пока идёт разговор (Ц-5)

Стадия: Для разработки. Подсказка — в приложении FlowMeet, а не в окне конференции. «Спросить ИИ» после звонка в требования не входит.

Роль цели: Ценность клиентского приложения, а не основание цены железа. Бизнес-план: цель Ц-5 (20.08.2026). По плану подсказки включает сам сотрудник.

Ключ задачи PRD: [ТРЕБУЕТ УТОЧНЕНИЯ]

О продукте: FlowMeet записывает рабочий разговор и кладёт его на карточку клиента в системе продаж. Звук, текст и архив остаются на сервере вашей компании, а не у стороннего вендора.

В примерах клиент — тестовое ООО «Норд», не живая компания.

Файл собран из `tools/sa_content_*.py` скриптом `tools/build_requirements.py`; правки вносятся в источник, не сюда.

## Глоссарий

Общий словарь постановки. Термины, которыми пользуется эта цель, — те же, что в остальных целях.

| Термин | Определение |
|--------|-------------|
| Разговор | Одна запись от старта до стопа. Идентификатор — `call_id` (в пакете клиента поле называется `recording_id`; это один и тот же идентификатор, имя закрепляется в ОВ-1.1). |
| Источник записи | Откуда звук: компьютер, телефон или диктофон. Передаётся вместе с разговором. |
| Устройственный канал | Приём звука и технических данных по ключу устройства (`enroll`, `stream`, `audio`). По этому каналу устройство не выбирает клиента и не читает систему продаж. |
| Карточка | Уже существующая карточка клиента в системе продаж; идентификатор — id карточки. FlowMeet карточек не создаёт. |
| Привязка | Подтверждённая связь разговора с карточкой. Источник: встреча календаря, у которой уже есть карточка; номер телефона контакта карточки; карточка, которую выбрал сотрудник. Название компании из речи привязкой не является. |
| Кандидат | Карточка, предположенная по речи. Хранится отдельно от привязки и до подтверждения сотрудником ничего не открывает и ничего не создаёт. |
| Тип разговора | Клиентский, «не клиент» (планёрка, собеседование, внутренний разбор) или не определён. |
| Канал «Встречи и звонки» | Существующий канал на карточке; туда же попадают встречи из календаря и почта. |
| Черновик полей | Значения из разговора на карточке, пока сотрудник не нажал «Подтвердить». |
| Касание | Клиентский разговор с подтверждённой привязкой, доехавший в канал «Встречи и звонки». Не отметка, поставленная руками; не планёрка; не запись в очереди. |
| Контур организации | Сервер организации: на нём звук, расшифровка и архив. Не облачный сервис вендора. |
| Очередь | Запись на устройстве, пока сервер организации недоступен или не подтвердил приём. |
| Приватная запись | Запись, которую сотрудник сделал приватной, если это разрешила организация: остаётся только на устройстве, всё, что уже ушло на сервер, отзывается. |
| Живая подсказка | Карточка подсказки на экране записи во время разговора: вид, заголовок, текст, источник. Не консультация после встречи и не «Спросить ИИ». |
| Профиль подсказок | Набор подсказок для вида работы (продажи, поддержка, найм, разработка). Задаёт организация. |

## Сквозные правила

| № | Правило | Содержание |
|---|---------|------------|
| СР-1 | Два контура записи | Устройство передаёт звук и технические данные разговора по устройственному каналу. Карточку выбирает вошедший сотрудник или серверная интеграция (календарь, телефония) отдельной операцией. Сервер проверяет, что карточка существует и что у сотрудника есть право на неё, и пишет аудит. Оба контура сходятся по `call_id`. |
| СР-2 | В продажи — только с привязкой | Событие в систему продаж создаётся только для клиентского разговора с подтверждённой привязкой. Без привязки запись хранится на сервере организации, в продажах нет ни события, ни задачи. |
| СР-3 | Кандидат — не привязка | Компания, узнанная по речи, не открывает факты карточки, не создаёт встречу и не считается касанием до подтверждения сотрудником. |
| СР-4 | Один разговор — одно событие | Повторная отправка того же разговора (тот же `call_id` и контрольная сумма файла) принимается как успех и второго события не создаёт. Поздняя привязка запускает доставку того же разговора, а не нового. |
| СР-5 | Во время разговора продажи не меняются | Ни запись, ни подсказка во время разговора ничего не пишут в систему продаж. |
| СР-6 | Запись не теряется | Нет связи — запись остаётся в очереди на устройстве и уходит на тот же сервер организации, когда связь появится. Очередь ничего не удаляет, пока сервер не подтвердил приём. |
| СР-7 | Приватная запись | Если организация разрешила, сотрудник может сделать запись приватной. Она остаётся на устройстве; всё, что уже ушло на сервер, отзывается. В продажи и в счёт касаний такая запись не попадает. |

## Бизнес-ценность

Сотрудник отвечает клиенту сразу, не уходя выяснять: нужное из базы знаний приходит на экран, пока разговор идёт.

## Цели

- Во время разговора подсказка видна в FlowMeet, а не в другом окне.
- Нет связи — живых подсказок нет, и это сказано прямо; запись всё равно доедет (Ц-2).
- Если привязка подтверждена, подсказка опирается на факты карточки; писать в карточку с подсказки нельзя.

**Мера:** Доля вопросов, закрытых подсказкой (П-20). Не мерили; миллисекунды не нормируются.

**Входит в контур:**

- показ карточки подсказки на экране записи;
- состояния: нет связи, выключены, нет данных клиента, меньше подсказок, лимит на встречу;
- опора на факты карточки при подтверждённой привязке (только чтение).

**Не входит:**

- «Спросить ИИ» и любой чат после звонка;
- пять готовых фраз постановщика — текст присылает сервер;
- корпоративное хранилище — на старте источник текста профиль организации;
- запись в систему продаж с подсказки.

---

## Проблемы

**AS-IS (как сейчас):**

Чтобы ответить по сроку, цене, контуру, сотрудник уходит в другую систему или в голову. База знаний в момент разговора на экране записи не лежит. «Спросить ИИ» после звонка эту боль не закрывает.

**Последствия:**

Пауза в разговоре, неточный ответ, обещание «уточню письмом».

**Масштаб:** Не мерили.

## Акторы и ролевая модель

| Актор | Описание | Права в рамках функции |
|-------|----------|------------------------|
| Сотрудник | Говорит с клиентом, смотрит FlowMeet. | По плану включает подсказки сам; администратор может выключить. |
| FlowMeet | Экран записи и карточка подсказки. | Не пишет в систему продаж во время разговора. |
| Сервер организации | Шлёт события подсказок на том же соединении, что звук. | Без связи живую подсказку не обещать. |
| Система продаж | Карточка клиента. | Только чтение для подсказки при подтверждённой привязке. |

## Пользовательские кейсы

### К-5.1. Подсказка в разговоре

Как сотрудник, я хочу видеть подсказку в FlowMeet, пока говорю, чтобы не уходить выяснять.

| | |
|--|--|
| **Актор** | Сотрудник |
| **Ситуация** | Идёт запись. Подсказки включены. Связь есть. Клиент задал вопрос по делу. |
| **Проблема сейчас** | Сотрудник уходит в другую систему или отвечает из головы. |
| **Ожидаемый результат** | На экране FlowMeet появляется карточка подсказки: вид, заголовок, текст, источник. Не окно конференции и не чат после звонка. |
| **Требования** | ФТ-5.1, ФТ-5.2, ФТ-5.7 |

### К-5.2. Клиент опознан

Когда клиент опознан, я хочу опереться на факты карточки (сделка, последний шаг), чтобы не выдумать.

| | |
|--|--|
| **Актор** | Сотрудник |
| **Ситуация** | Идёт встреча с ООО «Норд», привязка подтверждена сотрудником до или во время разговора. |
| **Проблема сейчас** | Подсказка выдумывает сумму и лицо, принимающее решение, или лезет писать в карточку. |
| **Ожидаемый результат** | В подсказке факты из карточки ООО «Норд», только чтение. В систему продаж во время звонка ничего не пишется. |
| **Требования** | ФТ-5.3, ФТ-5.7 |

### К-5.3. Клиент не опознан

Когда клиент не опознан, я хочу подсказку из профиля, а не остановленную запись.

| | |
|--|--|
| **Актор** | Сотрудник |
| **Ситуация** | Привязки нет; компания могла прозвучать в речи (кандидат). |
| **Проблема сейчас** | Либо запись стопается «пока не найдём карточку», либо подставляется чужая компания. |
| **Ожидаемый результат** | Подсказки идут из профиля организации. Запись продолжается. Факты чужой карточки не показываются. |
| **Требования** | ФТ-5.3, ФТ-5.8 |

### К-5.4. Нет связи

Когда нет связи, я хочу честно видеть, что живых подсказок нет, а не пустую ленту как «всё в порядке».

| | |
|--|--|
| **Актор** | Сотрудник |
| **Ситуация** | Сервер недоступен. |
| **Проблема сейчас** | Пустая лента выглядит как «подсказывать нечего». |
| **Ожидаемый результат** | На экране прямо: «живых подсказок нет». Запись идёт и доедет на сервер (Ц-2). |
| **Требования** | ФТ-5.4 |

### К-5.5. Подсказки выключены

Как сотрудник, я хочу включать подсказки сам, а не получать обязательный режим «всегда подсказывать».

| | |
|--|--|
| **Актор** | Сотрудник, администратор |
| **Ситуация** | Подсказки выключены сотрудником или администратором организации. |
| **Проблема сейчас** | Подсказки идут всегда, как обязательная запись, — это не цель Ц-5 плана. |
| **Ожидаемый результат** | Карточек нет, запись идёт. Причина названа: «подсказки выключены» или «выключены администратором». |
| **Требования** | ФТ-5.5 |

### К-5.6. Подсказок меньше обычного

Как сотрудник, я хочу знать, почему подсказок стало меньше, чтобы не ждать их напрасно.

| | |
|--|--|
| **Актор** | Сотрудник |
| **Ситуация** | Сервер сообщает о деградации: нет данных клиента, лимит на встречу исчерпан, подсказок меньше обычного, тестовый режим. |
| **Проблема сейчас** | Тишина выглядит как «подсказывать нечего». |
| **Ожидаемый результат** | Приложение показывает строку статуса с причиной. Это строка, а не карточка подсказки. |
| **Требования** | ФТ-5.6 |

## Corner-cases

- Подсказка «по таймеру», а не по сказанному, не показывается.
- Запись обязательна, подсказки выключены: карточек нет.

---

## Критерии приёмки

- **AC-5.1:** Запись идёт, подсказки включены, связь есть, есть что сказать → карточка в FlowMeet, не в окне конференции. (ФТ-5.1, ФТ-5.2)
- **AC-5.2:** Нет связи → живой карточки нет, сказано «живых подсказок нет», запись идёт. (ФТ-5.4)
- **AC-5.3:** Подсказки выключены → карточек нет, причина названа, запись идёт. (ФТ-5.5)
- **AC-5.4:** Клиент опознан → в подсказке только факты карточки или профиль; в систему продаж не пишется. (ФТ-5.3, ФТ-5.7)
- **AC-5.5:** Клиент не опознан → запись не остановлена, фактов чужой карточки нет. (ФТ-5.3, ФТ-5.8)
- **AC-5.6:** Нет экрана «Спросить ИИ» как замены живой подсказки. (ФТ-5.1)
- **AC-5.7:** Пустая карточка «пока нечем» не показывается. (ФТ-5.1)
- **AC-5.8:** Состояния подсказок показаны строкой статуса, а не карточкой. (ФТ-5.6)
